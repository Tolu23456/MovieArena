What the contract requires

1. The skip link is the first stop and reaches the main region.

2. DOM order is visual order. No tabindex="1".

3. Every ring is the same 2px hard outline at 2px offset.

4. Cards are one target; the heart is a separate button.

5. Focus is never covered by the sticky header or tab bar.

6. A route change moves focus to the new h1; Back returns it to the trigger.

Why not a dialog

The current header popup is role="dialog" with aria-expanded on a plain input. That mixes two patterns. Phase 9 locks one: combobox + listbox, options in the DOM, focus moves into options, Escape closes and restores the field.

Results are links. Enter follows the focused option. The live region announces the count, not every keystroke.

Dialog focus trap

Open, then Tab. Focus cycles inside. Escape closes and returns to the trigger. The page behind is inert for the pointer and the keyboard.

The dialog has aria-modal="true", a labelled title, a described body, and a close button with a name.

Forms and errors

Rules

Visible label, persistent help text, inline alert, and a summary when more than one field fails.

Required is stated in text and with the required attribute. The error border is not the only signal.

No puzzle, no memorised code, no time limit that expires while typing.

Live regions

One stable region per event type. Activate a button and read the log below; the same text is announced politely.

No announcements yet.

Announcement budget

Polite: saved, removed, filter count, playback state.

Assertive: errors only. Never use assertive for success.

Never: subtitle lines, hover, scroll position, clock ticks.

The node is created once and only its text changes. Recreating a live region loses the announcement.

Required props

Tab: accessibilityRole="tab", accessibilityState={{ selected }}.

Heart: its own button, label “Save …” / “Remove …”, state selected, 44px hit area.

Watch open: focus moves to the back button and title; closing returns it to the card.

WebView: native mirror controls for play, seek, mute, captions, fullscreen.

Type: 200% dynamic type must not clip. Decorative images are not focusable.

Mode checks

Approximate the modes that break most interfaces. The accent hue never changes; the system colours take over.

Forced colours replaces the surface with black, borders with white, and the action with yellow. Focus becomes cyan. The spinner is the documented exception that keeps rotating under reduced motion.
