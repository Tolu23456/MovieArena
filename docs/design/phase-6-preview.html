Components that stay quiet.

One anatomy and one token contract across classic, React, and native. Emphasis comes from contrast, weight, and spacing — never lift, zoom, parallax, or glow. Focus is always a hard ring at a fixed offset.

Foundations

Type, spacing, radius, and elevation. The scale is fixed; components do not invent values.

Buttons

Primary is the only filled button. One primary per view region. Pressed is fill plus scale(.98).

Variants and sizes

Focus any control to see the hard 2px ring at 2px offset. The primary uses focus.onAccent so the ring stays visible on the fill.

Fields

Search, text, select, checkbox, and switch. Errors use icon + text, never colour alone.
