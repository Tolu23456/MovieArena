One token system. Two real themes.

Graphite and paper are peers. The accent is for action, focus, and progress — not decoration. Light mode never uses the raw accent for text; it switches to the link token. Focus is a hard ring: no halo, no bloom, no ambient wash. Every ratio below is computed in the page from the live CSS variables.

Border rows are UI boundaries, not text, so the text columns are intentionally “—”. --color-border-subtle is decorative and never the only boundary of a control.
