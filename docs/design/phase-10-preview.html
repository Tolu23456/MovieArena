Legal rewrite

The current page is not one lie; it is several half-truths that contradict each other and the code. Replace it with dated statements and a launch addendum.

Current legal.html

  • “Every stream … is delivered by YouTube.”Contradicted later on the same page by the Archive direct-file paragraph.
  • “There is no user database and no analytics.”Written as a permanent promise; will be false when accounts ship.
  • “No streams … proxied.”Unqualified; the Archive relay is a proxy for public-domain files, and the code ships a ToS-gray playback proxy.
  • “Remove the show's entry from shows-data.js …”Not a contact path for a public site.
  • “taking the source down takes the entire site down”Overstated; the catalog entry can be removed independently.

Proposed current-state text

  • Official anime and donghua play through the rights-holder's own YouTube embed. The embed may show the rights-holder's ads.
  • Public-domain films play as direct files through MovieArena's range-aware relay. The relay only fetches files the source serves publicly.
  • MovieArena does not host, rip, re-upload, or proxy licensed video, and does not bypass DRM.
  • As of 7 Nov 2026, your list, progress, and settings stay on this device. There is no account and no analytics.
  • When accounts and optional analytics launch, this page lists the data, purpose, retention, processors, and deletion path before those features are enabled.
  • Rights-holder requests go to a contact address, with a response target. The catalog entry can be removed without touching the source.

Launch addendum — a release blocker

Accounts, profiles, optional analytics, ads, a third-party caption service, operator-curated links, payments, and push/email each require their own legal section in the same release. A release checklist item blocks the feature if the section is missing.
