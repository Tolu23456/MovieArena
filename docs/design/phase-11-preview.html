Five tabs: Home · Browse · Search · My List · More. Tab bar: 56pt + inset, 2pt accent rule, primary-colour label. Watch: per-tab stack, hardware back restores the exact origin.

What changes on the device

Theme: one semantic object; light, dark, system; no raw hex. Type: 11pt floor, 200% dynamic type. Targets: 44pt. Player: native direct-file engine, WebView only for YouTube, mirror controls. Trust: consent before collection, guest-first, Kids restricted or no ad promise.

Explicit Resume action
